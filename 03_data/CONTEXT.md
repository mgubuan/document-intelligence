# 03_data — answer questions about numbers

Generated by `_system/rebuild.py` from approved records. Never edit; delete and rebuild anytime.

- `invoices.db` — the relational database (schema in the root `CONTEXT.md`)
- `exceptions.md` — matching problems (missing or over-billed POs, payments to unknown invoices, overpaid invoices, invoices outside a contract term, rates above the contract, spend above contract value) and contract notice deadlines in the next 90 days

## Question → where to look
| They ask about | Use |
|---|---|
| spend, totals, by vendor / month / GL account | `invoices`, `line_items` (join on vendor + invoice_no) |
| what's unpaid, overdue, aging, due soon | `ap_aging` (open amounts > 0, with `days_past_due` and `bucket`) |
| paid / partial / overpaid, vendor credits | `invoice_balances` (negative `open_balance` = credit) |
| payments, methods, what a check paid | `payments`, `payment_applications` |
| open / over-billed / remaining POs | `po_status` |
| renewals, notice deadlines, missed windows | `deadlines` (status: upcoming, missed, later, ended) |
| what a contract says, agreed prices | `contract_terms` (cite `section`), `contract_rates` |
| what's flagged, why | `review_queue` |
| duplicates refused | `refused_duplicates` |
| mismatches | `exceptions` (kind + detail) |
| every document for a vendor, source PDF, who approved | `records` |
| "as of" date used for aging and deadlines | `settings` |
| how things relate | `python _system/graph.py "X" "Y"` |
| accrual at a month end | invoices dated ≤ month end, minus payments dated ≤ month end (see `_system/selftest.py` for the query) |

Worked queries for 100 common questions live in `_system/selftest.py`. Copy the closest one.

## Use it for
Totals, counts, dates, filters, GL breakdowns, and what's paid vs open: `python _system/q.py "SELECT ..."`
- Paid / open / overpaid → `SELECT * FROM invoice_balances`
- Billed vs ordered → join `invoices` to `purchase_orders` on vendor + po_no
- Renewals and notice dates → `SELECT * FROM contracts ORDER BY notice_deadline`
- What a contract says → `contract_terms` (cite the section); agreed prices → `contract_rates`
- Contract answers are a summary, not legal advice — point to the section so the user can read the source.

## Rules
- Group by `vendor` (clean), never `vendor_raw`.
- Join on both `vendor` and the document number.
- Cite the document numbers behind every answer.
- Flagged records are NOT in here. If the question could involve them, say how many are waiting (`rebuild.py` prints it).
- When asked for status, always mention anything in `exceptions.md`.
