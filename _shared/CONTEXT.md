# _shared — the factory: your approved names

Owned by the user (the bookkeeper). The agent reads these through the scripts and never edits them.

- `vendors.md` — real vendor names + every spelling seen (aliases)
- `chart-of-accounts.md` — GL accounts + keywords for coding line items
- `doc-types.md` — invoice, credit memo, statement, receipt

When an invoice gets flagged, the fix usually belongs here: add the alias or keyword once and it never flags again.
